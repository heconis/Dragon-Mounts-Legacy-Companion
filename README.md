# Dragon Mounts: Legacy Companion

懐いたドラゴンを指輪に紐づけ、召喚やミニオン化を行う Minecraft Forge 向けアドオンです。専用キーで通常召喚とミニオン化を切り替えられます。

- [要件定義書](docs/要件定義書.md)
- [技術調査・実装方針](docs/技術調査.md)

## 開発環境

Minecraft 1.20.1、Forge 47.4.10、JDK 17 を使用します。開発時は Gradle Wrapper が Dragon Mounts: Legacy 1.2.3-beta と Curios API 5.14.1+1.20.1 を取得します。

```powershell
.\gradlew.bat build
.\gradlew.bat runClient
```

専用サーバーの開発起動は `.\gradlew.bat runServer` を使用します。開発クライアントは `run/`、専用サーバーは `run-server/` にデータを作成します。

召喚の保存処理は `.\gradlew.bat runGameTestServer` で確認できます。`build/game-test-server/` のテストワールドでドラゴンを格納・再召喚し、エンティティの保存ファイルに同じ個体が記録されたことを検証します。

ワールドの `data/dmlcompanion_dragons.dat.d/` にはドラゴンごとの状態を保存します。以前の `data/dmlcompanion_dragons.dat` があるワールドでは両方を読み込み、個体別ファイルを優先します。バックアップにはワールドの `data/` ディレクトリも含めてください。

## エンダードラゴン討伐報酬とLootr

Lootrを導入すると、エンダードラゴン討伐後に帰還ポータルの台座に出る卵がLootrチェストに置き換わります。各プレイヤーはチェストの中央にある卵を1個ずつ受け取れます。再召喚の儀式が始まると前回のチェストは消え、次に倒すと新しいチェストが出ます。再討伐時の報酬には Dragon Mounts: Legacy の `replenish_eggs` 設定が適用されます。

連携を使う場合はサーバーと各クライアントに同じLootrを入れます。開発時は `-PwithLootr` を付けて `runGameTestServer` や `runClient` を実行できます。検証対象は [Lootr Forge 0.7.35.94](https://www.curseforge.com/minecraft/mc-mods/lootr/files/7263076) です。

## 指輪の動作確認

1. [GitHub Releases](https://github.com/heconis/Dragon-Mounts-Legacy-Companion/releases) またはローカルビルドの `build/libs/` から、このModのJARを入手して `mods` フォルダーに入れます。すでに導入済みの場合は旧版のJARと差し替えます。マルチプレイではサーバーと各クライアントに同じ版を入れます。
2. 確認済みの指輪があればそのまま使えます。新しく入手する場合は、まだ懐いていないドラゴンにバニラのアメジストの欠片を与えます。全品種で共通です。成功時に指輪が1個手に入ります。インベントリが満杯の場合は足元付近に落ちます。
3. Curios の Ring スロットに装備します。別のプレイヤーへの指輪の受け渡しと、Ring スロットが複数ある環境で2個目の装備を試すと、装備が拒否されます。

すでに懐いていたドラゴンへの遡及発行は行いません。指輪の表示名はドラゴンの個体名または種類名に基づきます。名札を使うと、インベントリや Curios にある指輪の表示名が約1秒で更新されます。チェストにある指輪は取り出したときに更新されます。

懐いたドラゴンの体力は、生の牛肉やステーキなど、魚以外の肉で回復できます。魚とアメジストの欠片を与えても回復しません。ドラゴンの繁殖は無効です。

指輪にカーソルを合わせると、品種・状態・体力を確認できます。結晶はドラゴンの品種に応じた色で表示され、ミニオン時は指輪にエンチャントアイテムと同じ光沢が流れます。死亡時は結晶が灰色、リングが銀色になります。通常召喚中の個体が未ロードの場合は、保存済みの体力に「最終確認時」と表示します。旧版で格納したドラゴンの最大HPは、記録がなければミニオンの回復処理が始まるか、一度召喚した後に表示されます。

## ミニオン化・召喚の動作確認

ミニオンのエンティティ名と召喚・ミニオン化の通知には、ドラゴンの個体名または種類名が使われます。

1. 指輪を Ring スロットに装備し、通常召喚中のドラゴンの近くで、騎乗せずに **K** を押します。ドラゴン本体が格納され、小型のドラゴンがプレイヤーの後ろを追従します。三人称視点（**F5**）で確認できます。
2. ミニオンがいる状態で指輪を外し、もう一度装備します。ミニオンが消え、再装備すると戻ります。
3. 1秒ほど待ち、広い場所を向いてもう一度 **K** を押します。前方に同じドラゴンが召喚されます。名前、体力、お座り、鞍も確認できます。空間不足の場合はミニオン状態を維持します。
4. 以前の版でドラゴンを格納していた場合は、最初に **K** を押すと通常召喚できます。

キーは **設定 → 操作設定 → キー割り当て → Dragon Mounts: Legacy Companion** で変更できます。

指輪を初めて入手すると、所有者に短いチャイムが鳴ります。キー操作で召喚すると出現した位置に白い粒子と羽音、ミニオン化すると通常ドラゴンがいた位置に紫の粒子と効果音が出ます。空間不足による召喚失敗や、再ログイン・再装備によるミニオンの再表示では、切り替えの演出は出ません。

Forge の **Mod 一覧 → Dragon Mounts: Legacy Companion → 設定** から、後方追従（初期値）、頭乗り、背中（全身）、背中（翼のみ）、非表示を選べます。頭乗りでは、ドラゴンはお座りポーズのまま頭頂の位置と頭の傾きに追従します。頭装備の有無で表示位置の高さを調整します。背中表示は胴体の動きに追従します。「背中（全身）」では通常時は立ち姿の翼をたたみ、滑空中は羽ばたきます。旧版の肩乗り設定は頭乗りとして読み込みます。「完了」を押すと、そのクライアントの `config/dmlcompanion-client.toml` に保存され、すぐに反映されます。

### ミニオン滑空

指輪を装備してミニオンを出し、ジャンプキー（初期設定はスペース）を約0.2秒以上押し続けると、落下中に滑空します。地上からジャンプして押し続けた場合も、下降に入ると滑空できます。キーを離すと通常の落下に戻り、その地点から落下距離を数え直します。後方追従では滑空中だけミニオンが背中で羽ばたき、頭乗りや背中表示では選んだ位置で羽ばたきます。Lv1から滑空でき、Lv4で横移動が走行程度まで速くなります。

### 友情レベル

指輪を装備してプレイした時間がドラゴンごとに蓄積します。通常召喚中の時間も加算します。初回のLvアップは20分、その後はレベルごとの必要時間が20分ずつ増え、装備時間15時間でLv10に到達します。指輪の名前に現在のLv、ホバーに次のLvへの進捗率と到達済みのLvの効果が1行ずつ表示されます。Lv10の指輪名は黄色になり、末尾に `[Max]` が付きます。レベルが上がると所有者に通知と効果音が出ます。

指輪を装備してミニオンが有効な間は、Lv2で採掘速度上昇Ⅰ、Lv3で移動速度上昇Ⅰ、Lv6で跳躍力上昇Ⅰ、Lv7で耐性Ⅰ、Lv9で攻撃力上昇Ⅰが順に加わり、効果時間は `∞` と表示されます。同じ種類のポーションやビーコンの効果がある間はそちらが優先されます。

### ミニオン飛行

Lv5以上の指輪を装備してミニオンを出します。空中でジャンプキーを短押しすると、キーを離したときに飛行を開始します。飛行中は視点で操縦でき、ジャンプキーを押し直すと、羽音とともに飛翔時間1のロケット花火と同じように加速します。ブーストを再使用できるまで3秒かかります。

飛行できる時間はLv5の飛行Ⅰで30秒、Lv8の飛行Ⅱで60秒、Lv10の飛行∞で無制限です。時間切れになると滑空へ移り、ジャンプキーを一度押すとその滑空を解除できます。その後はジャンプキー長押しで通常の滑空ができ、着地すると再び飛行できます。使用可能なエリトラを胴スロットに装備している場合は、通常のエリトラ飛行が優先されます。

飛行中はHUDにエリトラのアイコンが表示され、インベントリの「飛行」エフェクト欄で残り時間を確認できます。

ミニオン飛行中にワールドを退出した場合、同じ指輪が装備されていてミニオンが有効なら、再入場時に飛行を再開します。退出中は飛行の残り時間とブーストのクールタイムが止まります。

ミニオン飛行中や滑空中は通常召喚が制限されます。着地するか滑空を解除してから、キー操作で召喚できます。

### 通常ドラゴンの騎乗

手懐けて鞍を付けたドラゴンに飼い主が乗ったら、もう一人が空の手でドラゴンを右クリックして後ろに乗れます。操縦は飼い主が行います。後席からは通常の降りるキー（初期設定では左Shift）で降りられます。飼い主が先に降りた場合は、空の手で右クリックすると前席に戻れます。

二人乗りをしたドラゴンはワールドに保存されます。騎乗中にログアウトしたプレイヤーは、再入場時に同じディメンションでドラゴンが読み込まれ、席が空いていれば元の席に戻ります。後席のプレイヤーが先に再入場した場合も、飼い主が戻ると前席で操縦できます。

飼い主が操縦する通常ドラゴンの飛行速度は、そのドラゴンの友情レベルに応じて上がります。Lv1 は1倍、Lv2 は約1.11倍、Lv5 は約1.44倍、Lv10 は2倍です。一人乗りと二人乗りで同じ倍率が適用されます。

ミニオンは指輪を装備したまま再ログインやディメンション移動をしたときにも再表示されます。プレイヤー死亡後は、指輪が装備された状態でリスポーンするか、落とした指輪を拾って再装備すると、ミニオンが戻ります。

指輪を装備してミニオンにしてから30秒経つと、ドラゴン本体が1 HP回復します。その後は10秒ごとに1 HP、最大HPまで回復します。回復分は指輪のホバーと再召喚した個体に反映されます。指輪を外したり、通常召喚・ログアウトしたりすると回復が止まり、条件を満たし直してから30秒で再開します。ミニオンの表示設定が「非表示」でも回復します。

通常召喚中にプレイヤーが死亡したときも、装備中の指輪に対応する個体をミニオンとして格納します。リスポーン後、指輪を装備していればミニオンが表示されます。通常個体が未ロード、騎乗中、またはリードでつながれている場合は、その場に残ります。
