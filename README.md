# Dragon Mounts: Legacy Companion

懐いたドラゴンを指輪に紐づけ、召喚やミニオン化を行う Minecraft Forge 向けアドオンです。専用キーで通常召喚とミニオン化を切り替えられます。

- [要件定義書](docs/要件定義書.md)
- [技術調査・実装方針](docs/技術調査.md)

## 開発環境

Minecraft 1.20.1、Forge 47.4.10、JDK 17 を使用します。開発時は Gradle Wrapper が Dragon Mounts: Legacy 1.2.3-beta と Curios API 5.14.1+1.20.1 を取得します。

```powershell
.\gradlew.bat build
.\gradlew.bat runClient
```

専用サーバーの開発起動は `.\gradlew.bat runServer` を使用します。開発クライアントは `run/`、専用サーバーは `run-server/` にデータを作成します。

## 指輪の動作確認

1. ビルドした `build/libs/dragon-mounts-legacy-companion-0.3.8.jar` に差し替えます。マルチプレイではサーバーと各クライアントに同じ版を入れます。
2. 確認済みの指輪があればそのまま使えます。新しく入手する場合は、まだ懐いていないドラゴンを DML の通常手順で懐かせます。成功時に指輪が1個手に入ります。インベントリが満杯の場合は足元付近に落ちます。
3. Curios の Ring スロットに装備します。別のプレイヤーへの指輪の受け渡しと、Ring スロットが複数ある環境で2個目の装備を試すと、装備が拒否されます。

すでに懐いていたドラゴンへの遡及発行は行いません。指輪の表示名はドラゴンの個体名または種類名に基づきます。名札を使うと、インベントリや Curios にある指輪の表示名が約1秒で更新されます。チェストにある指輪は取り出したときに更新されます。

## ミニオン化・召喚の動作確認

1. 指輪を Ring スロットに装備し、通常召喚中のドラゴンの近くで、騎乗せずに **K** を押します。ドラゴン本体が格納され、小型のドラゴンがプレイヤーの後ろを追従します。三人称視点（**F5**）で確認できます。
2. ミニオンがいる状態で指輪を外し、もう一度装備します。ミニオンが消え、再装備すると戻ります。
3. 1秒ほど待ち、広い場所を向いてもう一度 **K** を押します。前方に同じドラゴンが召喚されます。名前、体力、お座り、鞍も確認できます。空間不足の場合はミニオン状態を維持します。
4. 以前の版でドラゴンを格納していた場合は、最初に **K** を押すと通常召喚できます。

キーは **設定 → 操作設定 → キー割り当て → Dragon Mounts: Legacy Companion** で変更できます。

Forge の **Mod 一覧 → Dragon Mounts: Legacy Companion → 設定** から、後方追従（初期値）、肩乗り、非表示を選べます。肩乗りでは、バニラのオウムと同じ肩の位置を基準に、ドラゴンが背中側から前足を肩に添える形で表示されます。「完了」を押すと、そのクライアントの `config/dmlcompanion-client.toml` に保存され、すぐに反映されます。

ミニオンは指輪を装備したまま再ログインやディメンション移動をしたときにも再表示されます。プレイヤー死亡後は、指輪が装備された状態でリスポーンするか、落とした指輪を拾って再装備すると、ミニオンが戻ります。

通常召喚中にプレイヤーが死亡したときも、装備中の指輪に対応する個体をミニオンとして格納します。リスポーン後、指輪を装備していればミニオンが表示されます。通常個体が未ロード、騎乗中、またはリードでつながれている場合は、その場に残ります。
