Dragon Mounts: Legacy Companion
要件定義書 v1.0
対象Minecraft：1.20.1
Mod Loader：Minecraft Forge
前提Mod：Dragon Mounts: Legacy
必須API：Curios API
文書状態：基本仕様確定・技術調査前
1. 概要
1.1 Modの目的

Dragon Mounts: Legacy のアドオンModとして、プレイヤーに懐いたドラゴンを専用の指輪に紐づけ、召喚・格納・ミニオン化できる機能を追加する。

プレイヤーはドラゴンを通常サイズでワールドに召喚したり、小型のミニオンとして連れ歩いたりできる。

また、複数のドラゴンを飼育し、通常サイズのままワールドに出現させておくことも可能とする。

1.2 基本コンセプト
懐いたドラゴンごとに専用の指輪を入手できる。
指輪とドラゴンは固有IDによって紐づけられる。
指輪をCuriosのRingスロットに装備することで、そのドラゴンを操作できる。
任意のキー操作でドラゴンの召喚・ミニオン化を切り替えられる。
ミニオン状態では小型化したドラゴンがプレイヤーに追従する。
通常サイズのドラゴンは複数体同時にワールドへ存在できる。
2. 動作環境・依存関係
項目        要件
Minecraft        1.20.1
Mod Loader        Forge
前提Mod        Dragon Mounts: Legacy
必須API        Curios API
動作形態        Dragon Mounts: Legacyのアドオン

Curios APIは必須依存とし、CuriosのRingスロットを利用する。

3. 指輪の仕様
3.1 指輪の入手
Dragon Mounts: Legacyの既存の仕組みでドラゴンを孵化・成長させる。
成長したドラゴンに魚を与え、懐いたタイミングで指輪を自動入手する。
指輪はドラゴン1体につき1個のみ生成される。
指輪には対応するドラゴンの固有IDを保存する。
指輪には最初にドラゴンを懐かせたプレイヤーのUUIDを保存する。
3.2 指輪の名称

ドラゴンの種類と個体名に応じて指輪の表示名を変更する。

名前を付けていない場合

例：

火ドラゴンの指輪
氷ドラゴンの指輪
雷ドラゴンの指輪
名前を付けている場合

例：

ファイアの指輪
シルバーの指輪
ボルトの指輪

ドラゴンに名前を付ける方法として、Minecraft標準の名札に対応することを目指す。

ドラゴンの名前が変更された場合、指輪の表示名も更新する。

※Dragon Mounts: Legacy側の名札対応状況は技術調査で確認する。

3.3 指輪の装備
CuriosのRingスロットを利用する。
Ringスロットが複数存在しても、ドラゴンの指輪は同時に1個まで装備可能とする。
どちらのRingスロットに装備してもよい。
2個目のドラゴンの指輪を装備しようとした場合は拒否する。
インベントリに複数の指輪を所持することは可能。
3.4 指輪の所有者制限
指輪は最初にドラゴンを懐かせたプレイヤーに紐づく。
指輪を他のプレイヤーに渡しても、そのプレイヤーは使用できない。
所有者の変更・譲渡機能は設けない。
3.5 指輪の紛失
指輪を紛失した場合、原則として再入手不可とする。
同じドラゴンに対する指輪の再発行は行わない。
指輪をチェストなどに保管することは可能。
指輪の複製によって同一ドラゴンを複数管理できないようにする。
3.6 指輪の取り外し

指輪を取り外した場合の挙動は、ドラゴンの状態によって異なる。

ドラゴンの状態        指輪を外した場合
格納状態        変化なし
通常召喚状態        ドラゴンはワールドに残る
ミニオン状態        ミニオンEntityを削除し、ドラゴンを格納状態にする

通常召喚状態のドラゴンは、指輪を外してもワールドに存在し続ける。

これにより、複数のドラゴンを通常サイズでワールドに並べることができる。

ミニオン状態の場合は、指輪を外すと表示用のミニオンEntityのみを削除する。ドラゴン本体のデータは失わない。

再び同じ指輪を装備すると、ミニオンEntityを再生成する。

4. ドラゴンの状態管理
4.1 基本状態

ドラゴンは以下の3状態を持つ。

① 格納状態
通常のドラゴンEntityはワールドに存在しない。
ドラゴンの情報はデータとして保存される。
指輪のキー操作で通常召喚できる。
② 通常召喚状態
Dragon Mounts: Legacyの通常ドラゴンEntityとしてワールドに存在する。
通常サイズで活動する。
追従・お座りなど、既存Modのドラゴンの行動を維持する。
指輪を外してもワールドに残る。
複数体のドラゴンが同時に存在してもよい。
③ ミニオン状態
通常ドラゴンEntityを格納する。
ミニオン専用Entityを生成する。
ミニオンはプレイヤーに追従する。
指輪を外すとミニオンEntityを削除する。
再装備するとミニオンEntityを再生成する。
4.2 状態遷移

基本的なキー操作による状態遷移は以下の通り。

現在の状態        キー操作後
格納状態        通常召喚状態
通常召喚状態        ミニオン状態
ミニオン状態        通常召喚状態

キー操作は装備中の指輪に対応するドラゴンだけを対象とする。

指輪を装備していないドラゴンや、別の指輪に紐づくドラゴンには影響しない。

5. 召喚・格納仕様
5.1 通常召喚
指輪を装備した状態で専用キーを押すとドラゴンを召喚する。
ドラゴンは通常サイズでワールドに出現する。
元のドラゴンの情報・状態を可能な限り復元する。
5.2 ミニオン化
通常召喚状態で専用キーを押すとミニオン化する。
通常ドラゴンEntityの情報を保存する。
通常ドラゴンEntityをワールドから取り除く。
ミニオン専用Entityを生成する。
5.3 再召喚
ミニオン状態で専用キーを押すと通常召喚状態に戻る。
ミニオンEntityを削除する。
保存していた通常ドラゴンの情報を復元する。
5.4 召喚可能な空間の確認

ドラゴンを召喚する前に、召喚位置に十分な空間があるか確認する。

空間が不足している場合は召喚を拒否する。
別の場所を探して召喚することはしない。
指輪は装備状態を維持する。
ドラゴンは格納状態のまま維持する。
召喚失敗の理由をチャットメッセージで通知する。

メッセージ例：

「ドラゴンを召喚できません。周囲に十分な空間がありません。」

6. ミニオン仕様
6.1 基本仕様
ミニオンは通常ドラゴンとは別の専用Entityとして実装する方向とする。
ミニオンの大きさはおおむね1ブロック程度。
通常ドラゴンのモデル・テクスチャを再利用できるか調査する。
ミニオンは見た目と追従を担当する。
ドラゴン本体の情報は別途保存して管理する。
6.2 追従方法

デフォルトではプレイヤーの後方を追従する。

基本的な位置：

プレイヤーの後方約1.5～2ブロック。
プレイヤーの頭より少し上。
プレイヤーの向いている方向を基準に位置を決定する。

基本的な動き：

プレイヤーの移動に滑らかに追従する。
急旋回時に瞬間移動せず、少し遅れて追従する。
高低差に対応する。
壁や地面に埋まらないようにする。
プレイヤー停止時は周辺でゆっくり浮遊する。

プレイヤーの前方には基本的に移動しない。

プレイヤーの攻撃・採掘・設置などの操作を妨げないことを優先する。

6.3 表示モード

Modのクライアント設定から以下を選択できる。

モード        内容
後方追従        プレイヤーの後方上空を追従する
頭乗り        お座りポーズでプレイヤーの頭頂の位置と頭の傾きに追従する。頭装備がある場合は頭頂との間隔を少し広げる。
非表示        ミニオンEntityを表示しない

デフォルトは後方追従とする。

設定はプレイヤーごとのクライアント設定とする。

6.4 ミニオンのダメージ・死亡

ミニオンは連れ歩き専用の存在とする。

基本的に無敵。
敵Mobから攻撃されない。
プレイヤーの攻撃も受けない。
ミニオン状態では体力を消費しない。
ミニオンEntityの消滅によってドラゴン本体が死亡することはない。
7. ドラゴンの状態保存・復元

ミニオン化・通常召喚・ログアウトなどで、ドラゴン本体の情報が失われないようにする。

7.1 保存対象
項目        優先度
ドラゴンの種類・属性        必須
成長段階・サイズ        必須
体力        必須
所有者情報        必須
ドラゴン固有ID        必須
お座り・追従状態        必須
名前・名札        必須
インベントリ・装備        必須
その他の固有データ        可能な限り保存
騎乗関連の状態        要調査
7.2 状態の復元
ミニオン化前のドラゴンの状態を保存する。
再召喚時には保存した状態を復元する。
お座り状態ならお座り状態で復元する。
追従状態なら追従状態で復元する。
体力や成長段階なども維持する。
8. プレイヤーの死亡・ログアウト・ディメンション移動
8.1 プレイヤー死亡時
ミニオン状態の場合は表示用Entityを削除し、本体データとミニオン状態を保持する。
リスポーン後も指輪を装備していれば、ミニオンを再表示する。指輪を落とした場合は、拾って再装備するとミニオンを再表示する。
通常召喚状態でも、装備中の指輪に対応するドラゴンをミニオンとして格納する。リスポーン後は、指輪が装備された状態か再装備したときにミニオンを表示する。
8.2 ログアウト時

ログアウト時は、ログアウト直前のドラゴンの状態を維持する。

ミニオン状態ならミニオン状態を維持する。
通常召喚状態なら通常召喚状態を維持する。
お座り・追従などの状態も維持する。
ログアウトを理由に自動格納しない。
騎乗中のログアウト

ドラゴンに騎乗して飛行している状態でログアウトした場合も、可能な限り騎乗状態を復元する。

ドラゴンの位置・向き・体力を保存する。
プレイヤーとドラゴンの騎乗関係を復元する。
騎乗関係の復元に失敗した場合は、ドラゴンをプレイヤーの近くに通常サイズで出現させる。
プレイヤーやドラゴンが消失しないことを優先する。
8.3 ディメンション移動
ミニオン状態のドラゴンはプレイヤーと一緒にディメンション移動する。
ネザー・エンドなどへの移動にも対応する。
ディメンション移動によってドラゴンのデータが失われないようにする。
9. ドラゴンの死亡
9.1 通常召喚状態での死亡
ドラゴンが死亡した場合、対応する指輪は残る。
指輪からドラゴンを復活させることはできない。
指輪は使用不能となる。
死亡したドラゴンの情報と指輪の対応関係を適切に管理する。
9.2 ミニオン状態

ミニオンは無敵であるため、ミニオン状態での死亡は基本的に発生しない。

10. キー操作
プレイヤーが任意のキーを設定できるようにする。
指輪を装備している場合のみ有効とする。
複数の指輪をインベントリに所持していても、操作対象は装備中の指輪に対応するドラゴンのみとする。
キー操作によって通常召喚・ミニオン化を切り替える。
11. 複数ドラゴンの管理

複数のドラゴンを同時に飼育できることを前提とする。

例：

ドラゴン        状態
火ドラゴン        通常召喚
氷ドラゴン        通常召喚
雷ドラゴン        通常召喚
風ドラゴン        ミニオン
通常サイズのドラゴンは複数体同時にワールドに存在できる。
指輪を外しても通常サイズのドラゴンはそのまま残る。
ミニオンとして連れ歩けるドラゴンは、装備中の指輪に対応する1体のみ。
別のドラゴンの指輪に切り替えても、既存の通常ドラゴンには影響しない。

14. 開発方針

本ModはDragon Mounts: Legacyの既存機能を可能な限り利用し、独自実装を必要最小限にする。

特に以下を重視する。

既存ドラゴンの育成・行動仕様を壊さない。
ドラゴンのデータ消失・複製を防ぐ。
通常ドラゴンとミニオンEntityの役割を明確に分離する。
複数ドラゴンの同時飼育に対応する。
シングルプレイ・マルチプレイの両方で正常に動作する。
ワールド再起動後もドラゴンと指輪の紐づけを維持する。

以上を本Modの基本要件とする。
